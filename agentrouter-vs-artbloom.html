有 GitHub 老账号和新账号，分别怎么选？

先对照表中的注册条件和自己的 GitHub 账号注册时间。符合老账号条件时，可以继续比较工具支持；不符合时，优先查看标注“注册即可用”的入口。账号门槛与模型支持是两项独立条件，能注册不代表每个客户端都能接入。

只用 Claude Code，或还要接 Codex？

Claude Code 与 Codex 使用不同的 API 协议。选择前应同时核对站点的接口文档、模型 ID 和客户端要求；仅提供 Anthropic 兼容接口的站点不能直接当作 Codex provider。表中只列已有记录中的工具支持，模型名字包含 GPT 或 Claude 不能代替接口兼容性检查。

  • 查看 Claude Code / Codex 的配置步骤与报错排查

免费额度是 API 余额，能用多久？

赠额是站点账户里的 API 调用余额，不等于 Claude 或 ChatGPT 的官方订阅，也不是可提现金额。能用多久取决于模型、上下文长度、请求量和站点计费规则。先用短请求确认返回正常，再观察余额变化，能更直接地判断自己的使用成本。

注册后看不到赠额时，核对邀请链接、登录状态和站点领取规则。无需为了领额度重复注册；先查看控制台与公告，再联系站点支持。
