QUICK START

Got a key? Configure your tool

Full setup guide (中文) ↗

Point requests to the relay's endpoint. Claude Code uses environment variables; Codex uses config.toml. Minimal examples follow.

  1. 1

    Claude Code

    Set BASE_URL to the station's Anthropic-compatible endpoint and AUTH_TOKEN to its key. This sends Bearer authentication, which most listed relays expect instead of x-api-key.

    export ANTHROPIC_BASE_URL="https://<station-endpoint>"
export ANTHROPIC_AUTH_TOKEN="<station-key>"
export ANTHROPIC_MODEL="claude-opus-5"   # Set manually if model discovery fails

claude

    For persistent setup, use your shell configuration or the env block in ~/.claude/settings.json. Never commit keys.

  2. 2

    Codex

    Add a custom provider in ~/.codex/config.toml. Use env_key to reference an environment variable instead of storing the key in the file.

    model = "gpt-5.6"
model_provider = "relay"

[model_providers.relay]
name = "relay"
base_url = "https://<station-endpoint>/v1"
env_key = "RELAY_API_KEY"
wire_api = "chat"

    Then export RELAY_API_KEY="<station-key>". The recorded example uses chat; relay support for Responses and client configuration may vary.

Common pitfalls

  • Whether base_url needs /v1 depends on the endpoint. Anthropic-compatible endpoints usually omit it because Claude Code appends /v1/messages; OpenAI-compatible endpoints usually include it. Wrong paths generally return 404 rather than 401.
  • Copy model IDs exactly. If discovery fails, enter the ID from the station's model list without changing case or hyphens.
  • Do not connect Codex to a station marked Claude Code only; it may expose only Anthropic-compatible endpoints.
  • 401 / 403 often indicate invalid keys or exhausted credits; 429 indicates rate limiting. Wait or use another station instead of repeatedly retrying.
  • Never commit keys or key-containing configuration. Use environment variables or a supported system keychain.

ANSWERS / FAQ

Before you start

Which station should I choose?

First check tool compatibility and signup requirements. AgentRouter is listed first, artbloom second. justwoker and kktoken are unavailable; their historical credits are for reference only.

What is an AI relay, and how does it differ from an official API?

A relay is a third-party service that forwards requests to models such as Claude or GPT, often with signup credits. It is not an official channel: operators control credits, pricing and referrals, and may change rules, throttle requests or shut down. Free credits may avoid the need for an overseas payment method.

What does the pricing multiplier mean?

It is a billing factor relative to official pricing. 1x deducts credits at the official rate; 0.65x deducts 65% of that rate. The same $100 credit therefore buys roughly half as many additional tokens at 0.65x compared with 1x.

How long do signup credits last?

It depends on token usage. Long-context Claude Code tasks can quickly consume tens of dollars. Some stations offer daily check-in credits; see individual records and current station rules.

Can I use these relays in Claude Code or Codex?

Where supported, use compatible endpoints. Claude Code uses ANTHROPIC_BASE_URL and ANTHROPIC_AUTH_TOKEN. Codex uses a custom provider in ~/.codex/config.toml with base_url and env_key. See the quick start examples and check current client requirements. Claude Code-only stations should not be used with Codex.

Are relays safe for company code?

Relays can see all request content. Do not send confidential code, production credentials or customer data through any third-party relay. Consider only content you are authorized to share, such as public project code or demos.

What if a station stops working?

Plan for interruptions and keep alternative endpoints. Contact the station for billing, bans or rate limits; this page only summarizes information. Records older than three months receive an age warning.

Why is my balance zero after registration?

Credits are often applied at login. Sign out and back in; some stations also require a manual claim or check-in. If the balance stays at zero, check announcements or contact support before registering again.

How do I troubleshoot 401 Unauthorized?

Check the complete key, remaining credit, allowed model ID and the authentication header expected by the station. Incorrect paths usually return 404. 403 often relates to permissions or credits; 429 indicates rate limiting, so wait or use an alternative.

What does 400 / content blocked mean?

The upstream may have rejected the content or language, although 400 can also indicate an invalid request. Check the error details and request format, then rephrase where appropriate or contact the provider.

How do I switch back to an official Claude subscription?

Environment variables override subscription login in Claude Code. Run unset ANTHROPIC_BASE_URL ANTHROPIC_AUTH_TOKEN ANTHROPIC_MODEL, then open a new terminal. Also remove persistent entries from your shell configuration or the env block in ~/.claude/settings.json.

Can I connect from mainland China without a proxy?

It depends on the station. Some provide directly reachable mirrors, while others require a proxy. Mirror addresses can change; use the station's current documentation rather than guessing.

ALTERNATIVES

Backup options: official and platform free tiers

Check model providers and platforms for free tiers. Models and operators differ: OpenRouter, for example, is an aggregator. Verify region availability, data policies, quotas and rate limits. Continued free access and availability are not guaranteed.

  • Google AI Studio → Gemini models with free quotas, long context and OpenAI-compatible endpoints.
  • Groq → A fast, OpenAI-compatible inference free tier for low-latency use cases.
  • OpenRouter → An aggregator with models tagged :free, accessible through one key.
  • Cloudflare Workers AI → Daily free quotas on edge infrastructure for integrating AI into apps.
  • ModelScope (Alibaba) → Direct access from mainland China with daily free quotas, focusing on Chinese models.
  • Zhipu AI (GLM) → Free GLM models with direct mainland China access and strong Chinese-language support.

READ BEFORE USE

Know the limits before using a relay

A listing records a test at a particular time. It is not a guarantee or promise of service.

  • Credits, pricing and referral rules can change Stations may throttle requests or shut down. Check current announcements, especially when a test record is over three months old.
  • Relays can see all request content Do not send confidential code, production credentials or customer data through third-party relays, regardless of the operator.
  • Plan for service interruptions Keep alternatives and avoid making a relay your only endpoint.
  • Upstream sources and model identity are not guaranteed This directory does not continuously audit upstream channels, model routing or response quality. Model labels and operator claims are not independent verification.
